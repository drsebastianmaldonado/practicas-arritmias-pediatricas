# Prácticas en arritmias en pacientes pediátricos

Banco de casos clínicos de arritmias pediátricas (ECG y Holter), con preguntas de opción múltiple, devolución, patrones de
referencia, scores clínicos, calculadoras (QTc, Z-score, HCM Risk), modo examen y glosario.

🔗 Sitio: https://drsebastianmaldonado.github.io/practicas-arritmias-pediatricas/

(plantillas, clave de respuestas, scripts de generación) se mantiene aparte, fuera de este repositorio público.
